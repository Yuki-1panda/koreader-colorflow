# 循彩阅读

“循彩阅读”是面向 KOReader 2026.07.2 的 EPUB 实时正文五色渐变插件。它在页面排版和绘制完成后，根据文字位置对正文像素上色，不会改写原 EPUB。

## 功能

- 默认“标准 48 字”，另有“舒缓 96 字”周期。
- 保留黑、蓝、紫、红、橙五色色锚。
- 插件入口位于阅读界面的“工具”页。
- 开关和周期按书保存，互不影响。
- 异常时自动停用并写入 KOReader 日志。
- 内部插件目录和设置键保持 `segment-tint-live`，便于兼容已有设置。

## 下载与安装

下载仓库中的 `koreader-colorflow-0.1.0-beta.1.zip`。完整退出 KOReader 后解压，将整个 `segment-tint-live.koplugin` 文件夹复制到 `koreader/plugins/`。重新启动 KOReader，打开 EPUB，在“工具”页找到“循彩阅读”。

## 已验证

在 Kindle Colorsoft、KOReader 2026.07.2 上已验证：

- 正文五色渐变正常。
- 翻页流畅，开启无明显卡顿。
- A、B 两本书可分别保存启用状态和 48/96 字周期。
- 修改字号、切换方向、连续翻页、双栏和夜间模式正常。
- 分页与连续模式切换后首屏坐标正常。

桌面测试：1753 条核心断言、18 条模拟接入断言和 Lua 语法检查通过。详情见 [TEST-RESULTS.md](TEST-RESULTS.md)。

## 待社区验证

长期速度和内存、更多设备与复杂排版，以及 48/96 字周期的主观阅读体验仍需社区反馈。请使用 [社区测试模板](COMMUNITY-TESTING.md)。

## 已知边界

- 连续模式实际滑动未在当前设备完成验证；分页与连续模式切换已验证。
- 英文比例字体按单词框等分，颜色边界可能落偏。
- RTL、连字、竖排和复杂嵌入排版尚未处理。
- 阅读体验属于主观反馈，不能据此作出医疗或治疗效果结论。

## 回退

如出现空白页或界面异常，退出 KOReader，删除 `koreader/plugins/segment-tint-live.koplugin` 文件夹即可。若仍能进入菜单，也可先关闭插件。
